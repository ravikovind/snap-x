Features

Everything you need
to ship great images

A zero-config render pipeline for branded social and marketing images.

🚀

No browser. No config.

Pure Node.js pipeline powered by Satori + resvg-js. Renders 4 images in under 2 seconds, anywhere npm runs.

🎨

Design files as code

Self-contained .mjs files. Everything hardcoded — fonts, colors, assets. Version-controlled, diffable, portable.

🔤

Any Google Font, one line

Load any weight of any Google Font. Emoji rendered as Twemoji. Automatic fallbacks for CJK, Arabic, Hebrew, Devanagari, and more.

📐

Every platform format

OG cards, YouTube thumbnails, X banners, LinkedIn covers, Instagram posts, App Store screenshots, Play Store graphics — built-in.

🤖

AI-native workflow

The /snap-x Claude Code skill analyzes your project, extracts branding, and writes + renders the full image pack automatically.

🔌

MCP server included

Validate and render designs from Cursor, Windsurf, or Claude Desktop via the @snap-x/mcp server.

Workflow

From project to image
in three steps

Write a design file, check it, render it. Or let Claude do all three.

Step 01

Write a design file

Export a default JSX function from an .mjs file. Declare canvas size, fonts, and layout. Everything in one file — no imports, no config.

og.mjs
→
Step 02

Check for errors

Run snap-x check to validate your design before rendering. Catch missing fonts, invalid props, and layout issues instantly.

snap-x check *.mjs
→
Step 03

Render to PNG

Run snap-x render to produce pixel-perfect PNGs. Add --guides to preview placement zones for any platform.

snap-x render *.mjs

Design Files

Code your design
once. Render anywhere.

Self-contained .mjs files. No external config. No runtime dependencies. Pure JSX.

og.mjs design file 
/** @type {import('@snap-x/core').Design} */
export default {
  width: 1200,
  height: 630,
  fonts: [
    { family: "Saira", weight: 900 },
    { family: "Saira", weight: 400 },
  ],
  render() {
    return (
      <div style={{
        background: "#070707",
        width: "100%",
        height: "100%",
        display: "flex",
        flexDirection: "column",
        padding: 64,
      }}>
        <h1 style={{
          fontFamily: "Saira",
          fontWeight: 900,
          fontSize: 80,
          color: "#f5f5f5",
        }}>
          snap-x
        </h1>
      </div>
    );
  },
};

A design is just a module

Export a render() function and declare your canvas size and fonts. snap-x handles the rest — font loading, emoji, fallback scripts.

No imports or external packages
Fonts declared inline, loaded automatically
Works with PNG, JPEG, SVG and base64 assets
Supports async render() for dynamic assets
Emoji rendered as Twemoji, cached locally
