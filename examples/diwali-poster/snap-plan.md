# Diwali poster plan (source: a written brief only — no repo, no website)

A festival greeting poster for a fictional company, "VoltVave Innovations" — a placeholder brand name
for this test, not a real business. Built to check snap-x on a very different visual style from the
rest of the examples: warm cream background, gold/red festival palette, a mandala ring, scattered
stars, and an emoji centerpiece — no photo, no real logo.

Regenerate: `npm run examples` (or `npx -y @snap-x/cli render examples/diwali-poster/designs --out examples/diwali-poster`)

## Rubric
1. Name: VoltVave Innovations (fictional placeholder — no such company)
2. Description: none given — generic seasonal/festival greeting graphic
3. Domain: "voltvave.com" shown in the footer is part of the fictional placeholder, not a real, resolvable site
4. Tags/proof: none invented
5. Surface: a single square-ish poster (1080×1350 — the same size as the `instagram-post` format)
6. Font: Saira 300/400/600/700/800/900 (this repo's own display font, reused here for a completely different palette/mood)
7. Accent: gold (#D4860A / #F5A800) and red (#eb1d25) on a warm cream background (#fffbf2)
8. Theme: light, festive — mandala ring, floating gold stars, red corner brackets
9. Logo: none — text wordmark "VoltVave Innovations" only

## Hook
"Wishing you a Happy Diwali" — a seasonal greeting, not a product pitch.

## Formats
- Custom 1080×1350 poster (matches the `instagram-post` format's dimensions, though this file isn't tied
  to that format id specifically — it's a general-purpose festival poster).

## Assumptions / mock
- "VoltVave Innovations" and "voltvave.com" are both fictional placeholders invented for this test pack —
  not a real company, not a resolvable domain.
- No real logo — the wordmark is plain text, no drawn mark.
