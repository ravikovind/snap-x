# Diwali poster plan (source: voltvave.com)

A festival greeting poster for VoltVave Innovations — a real software development and Zoho
implementation firm (Bengaluru/Srinagar) that snap-x's own author co-founded. Built to check snap-x
on a very different visual style from the rest of the examples: warm cream background, gold/red
festival palette, a mandala ring, scattered stars, and an emoji centerpiece — no photo, no drawn logo.

Regenerate: `npm run examples` (or `npx -y @snap-x/cli render examples/diwali-poster/designs --out examples/diwali-poster`)

## Rubric
1. Name: VoltVave Innovations (real company, voltvave.com)
2. Description: software development / Zoho implementation firm — this poster is a generic seasonal
   greeting, not a product pitch, so none of their specific services/products are named
3. Domain: voltvave.com (real, shown in the footer)
4. Tags/proof: none invented — no stats or claims beyond the greeting itself
5. Surface: a single square-ish poster (1080×1350 — the same size as the `instagram-post` format)
6. Font: Saira 300/400/600/700/800/900 (this repo's own display font, reused here for a completely different palette/mood)
7. Accent: gold (#D4860A / #F5A800) and red (#eb1d25) on a warm cream background (#fffbf2)
8. Theme: light, festive — mandala ring, floating gold stars, red corner brackets
9. Logo: none — text wordmark "VoltVave Innovations" only

## Hook
"Wishing you a Happy Diwali" — a seasonal greeting, not a product pitch.

## Formats
- Custom 1080×1350 poster (matches the `instagram-post` format's dimensions, though this file isn't tied
  to that format id specifically — it's a general-purpose festival poster).

## Assumptions / mock
- No drawn logo — the wordmark is plain text (VoltVave's real logo image wasn't sourced for this pack).
